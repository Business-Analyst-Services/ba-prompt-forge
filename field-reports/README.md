# Field reports

A rubric score says a prompt is **well-formed**. A field report says it
**worked**. The second is harder to get and worth more.

The library scores a mean of 19.62/20, and that number should be treated with
suspicion: the prompts were written against the rubric that scores them. Paper
scores measure the author's discipline, not the prompt's effect on real work.
This folder is the correction.

## Adding one

Copy [`TEMPLATE.md`](TEMPLATE.md) to `<PROMPT-ID>-<yyyy-mm>-<your-handle>.md`
and fill it in. One prompt, one use, a few minutes to write.

```
field-reports/BB-01-D1-2026-09-jdoe.md
```

## What makes a report useful

- **What you changed.** The single most valuable field. If you had to rewrite the
  example or add three sentences of context before it worked, that is a defect in
  the prompt, and it is fixable.
- **What it cost.** Turns to a usable draft, and how much editing after.
- **Whether you would use it again.** A plain yes/no, before the caveats.

## Negative reports

Wanted, kept, and never edited out. A prompt that scores 20/20 and fails in
practice is the most useful thing this repo could learn. If a prompt wasted your
afternoon, say so - the fix starts there.

## De-identification

Same rule as the prompts themselves, and it matters more here because you are
writing about real work:

- No client, employer or project names. "A state government agency" is enough.
- No real figures, case numbers, names or dates that could identify a matter.
- No quotable extracts from real artefacts - describe the shape, not the content.

If you cannot describe what happened without identifying the work, do not file
the report.
