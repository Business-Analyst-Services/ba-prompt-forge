Use the library with an AI agent

Optional, and for a narrower audience. Copying and pasting a prompt works perfectly well — this page is for people who would rather install the library once than search it each time.

An agent skill is a file of instructions, named SKILL.md, that you hand to an AI assistant that supports them (Claude Code and Claude Desktop, among others). After that, the assistant knows how to do the job without you pasting anything.

If your AI assistant is Microsoft Copilot or ChatGPT, this will not apply to you — use the prompts directly instead.

The three that matter

  • Prompt router

    Describe your work; get the right prompt, filled in.

  • Prompt scorer

    Score any prompt out of 20 and fix the deductions.

  • Prompt forge

    Write a new prompt to library standard, or convert one.

Start with the router

A catalogue of 126 prompts is a homework assignment. The router is the answer to that: you describe the work in your own words — “I need acceptance criteria a tester can actually work from” — and it narrows, recommends one prompt, asks you for the placeholders, and hands back something you can paste. It is told, in as many words, never to show you a list of 126 anything.

Every prompt is also a skill

All 126 prompts convert to standalone skills. Open any prompt and choose the Agent skill tab to get its SKILL.md. Useful when you want one BA service always available without the router in front of it.

Two things to check before relying on a generated skill: the description decides when it triggers, so make sure it reads like the words you would actually use; and the worked example is inherited from the prompt, so it may need swapping for one from your own domain.
