Who it is for

You are: a BA practice lead.
The audience for the output: All practice BAs and assessors; HR for role profiles.

Target deliverables: Competency Frameworks, Career Pathways

What you need to fill in

  • [LIST]
  • [PROPOSE FROM THE L3 CATALOGUE OR LIST — e.g. elicitation, analysis & modelling, technical analysis, agile delivery, stakeholder management, strategic advisory, AI-augmented analysis]
  • [E.G. SFIA / IIBA OR 'NONE']

CARE + G.E.T.

The library's native format. Context, Action, Result/Format, Example, plus Generate -> Explain -> Test. Lossless: every rubric criterion has somewhere to go.

# CONTEXT
I am a BA practice lead. I am working on [PROJECT NAME AND ONE-LINE DESCRIPTION]. My work must respect my organisation's privacy, information-security and data-residency obligations. Everything I paste is de-identified or synthetic — if any input appears to contain real personal or sensitive data, stop and alert me before proceeding. Practice context: [PRACTICE SIZE, MIX OF PERMANENT/CONTRACT, DELIVERY PORTFOLIO SHAPE]. Levels: [LIST]. Competency areas wanted: [PROPOSE FROM THE L3 CATALOGUE OR LIST — e.g. elicitation, analysis & modelling, technical analysis, agile delivery, stakeholder management, strategic advisory, AI-augmented analysis]. Reference frameworks in use: [E.G. SFIA / IIBA OR 'NONE']. The audience for this output: All practice BAs and assessors; HR for role profiles.

# ACTION
Draft the competency framework: areas × levels with behavioural anchors that make assessment consistent. Draft the framework. Anchors must discriminate: if the same evidence could satisfy two adjacent levels, sharpen it — show me the cells you found hardest to separate.

Before drafting, ask me up to 5 clarifying questions about anything missing, then wait for my answers.

# RESULT / FORMAT
Matrix: competency area × level, each cell one observable behavioural anchor (what this person can be seen doing). Progression logic stated per area (what fundamentally changes level to level — scope, autonomy, ambiguity). Include an AI-augmented analysis area (using AI tools critically: prompt quality, output validation via G.E.T., knowing when not to use AI). Alignment notes to my reference framework where supplied. Keep the language professional, plain-English and appropriate for a business audience. Do not invent facts or figures: mark anything you could not verify from my inputs as [TBC] and any value you propose yourself as [PROPOSED — VALIDATE]. Treat the output as a first draft for my review, not a finished artefact.

# EXAMPLE
Example AI-competency anchor: "AI-augmented analysis × BA: uses library prompts with correct placeholders; always runs Explain and Test and can show one instance where validation caught an AI error. × Senior: adapts prompts to novel tasks, scores them on the 10-criterion scorecard, and coaches others' validation practice."

# VALIDATION (GENERATE -> EXPLAIN -> TEST)
Generate: produce the output requested above.
Explain: then break down, step by step, the logic you used to synthesise your answer - how you interpreted each of my inputs and why you structured the output the way you did.
Test: list the source references you used (my pasted inputs, earlier turns, or your general knowledge - label which is which); cross-reference the key facts in your output against those sources and flag anything that does not trace back to a source; and list every additional assumption you made so I can verify or correct it.

# Competency Framework (Levels & Behaviours)

Derived from `PL-03-D1` in the BA Prompt Forge library
(Practice Lead / Capability & Competency Management, scored 20/20
against the CARE + G.E.T. rubric).

## When to use this

The user is doing capability & competency management work and needs one of:
- Competency Frameworks
- Career Pathways

The audience for whatever you produce is: **All practice BAs and assessors; HR for role profiles**.

## Before you start

The user's work must respect the user's organisation's privacy, information-security and data-residency obligations. Everything the user pastes is de-identified or synthetic — if any input appears to contain real personal or sensitive data, stop and alert them before proceeding.

Collect these inputs from the user. Do not guess them:

1. `[PROJECT NAME AND ONE-LINE DESCRIPTION]`
2. `[PRACTICE SIZE, MIX OF PERMANENT/CONTRACT, DELIVERY PORTFOLIO SHAPE]`
3. `[LIST]`
4. `[PROPOSE FROM THE L3 CATALOGUE OR LIST — e.g. elicitation, analysis & modelling, technical analysis, agile delivery, stakeholder management, strategic advisory, AI-augmented analysis]`
5. `[E.G. SFIA / IIBA OR 'NONE']`

Then ask up to 5 clarifying questions about anything still
missing, and **wait for the answers** before drafting.

## What to produce

- Draft the competency framework: areas × levels with behavioural anchors that make assessment consistent. Draft the framework. Anchors must discriminate: if the same evidence could satisfy two adjacent levels, sharpen it — show me the cells you found hardest to separate.

Format the output exactly as follows:

> Matrix: competency area × level, each cell one observable behavioural anchor (what this person can be seen doing). Progression logic stated per area (what fundamentally changes level to level — scope, autonomy, ambiguity). Include an AI-augmented analysis area (using AI tools critically: prompt quality, output validation via G.E.T., knowing when not to use AI). Alignment notes to the user's reference framework where supplied.

Keep the language professional, plain-English and appropriate for a business audience.

## Rules

- Do not invent facts or figures: mark anything you could not verify from the user's inputs as [TBC] and any value you propose yourself as [PROPOSED — VALIDATE].
- Treat the output as a first draft for the user's review, not a finished artefact.
- Do not ask the user to paste real personal or sensitive data.

## Worked example to imitate

Example AI-competency anchor: "AI-augmented analysis × BA: uses library prompts with correct placeholders; always runs Explain and Test and can show one instance where validation caught an AI error. × Senior: adapts prompts to novel tasks, scores them on the 10-criterion scorecard, and coaches others' validation practice."

## Before you hand it back

1. **Explain** - break down, step by step, the logic you used: how you interpreted
   each input and why you structured the output the way you did.
2. **Test** - list the sources you drew on (the user's inputs, earlier turns, or
   your own general knowledge; label which is which), cross-reference the key facts
   against them, flag anything that does not trace back to a source, and list every
   assumption you made so the user can verify or correct it.
